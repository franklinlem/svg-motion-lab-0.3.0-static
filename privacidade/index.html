Início / Projeto

Seus arquivos ficam com você

O SVG Motion Lab processa SVGs e projetos no seu navegador. Não há conta, upload de projeto, backend, anúncios ou analytics no editor.

O que fica salvo

A sessão atual e uma versão anterior são armazenadas no IndexedDB deste navegador. O tema fica no localStorage. O service worker guarda arquivos públicos da aplicação para uso offline; os arquivos importados não são armazenados como respostas de rede.

Autosave não é backup

O navegador ou o sistema podem apagar dados locais. Use Salvar JSON para guardar uma cópia portátil. Em modo privado ou sem espaço, o salvamento pode falhar; o editor informa o problema e continua permitindo exportação.

Apagar os dados

No editor, abra Ajuda e atalhos, depois Apagar dados deste dispositivo. Baixe o JSON antes se quiser continuar o projeto depois. Para remover também o cache offline, use a opção de limpar dados do site nas configurações do navegador.

Conexões necessárias

O navegador acessa a hospedagem para carregar páginas, código e exemplos. O provedor de hospedagem pode manter logs técnicos dessas requisições. O conteúdo de projetos não é incluído em URLs, metadados ou requisições de envio.

Uso offline

Depois de carregar o editor online e concluir o cache, ele pode abrir sem conexão. Uma atualização oferece exportação JSON antes de recarregar. O primeiro acesso exige rede.
